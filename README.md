# Welcome to My Backend Yelp
***

## Task
The purpose of the project was to create a business search platform similar to Yelp, with functionalities such as:

User sign-up and login system.

Ability to search for restaurants.

Add restaurants to the platform for business owners.

Secure routes that only allow logged-in users to add restaurants.

Create a scalable and maintainable backend system that can handle the above functionalities.

Description

## Description
I have created a full-stack application using React for the frontend and a Node.js backend to solve the problem. The backend handles authentication, user and business management, restaurant data storage, and serves as the API that interacts with the frontend.

Here’s a quick rundown of the solution:

User Management: Users can sign up and log in. On successful login, they are redirected to the homepage or restaurant listing.

Restaurant Search: Users can search for restaurants based on a query, and businesses can add their restaurants.

Business Login: A special section is available for businesses to log in and manage their restaurants.

## Installation
To get started with the project, follow the steps below:

Clone this repository:

git clone https://github.com/avongs4/my_backend_yelp.git
cd my_backend_yelp

Install dependencies:
npm install

Set up AWS Amplify&git
amplify configure
amplify init
amplify storage
amplify push

Set the project to start:
npm start


## Usage
The project allows users to interact with the following functionalities:

Sign up and Login for users.

Search for restaurants based on a query.

For Business Owners:
Add their restaurant.
Login to manage their restaurant listing.

The app uses React for the frontend and handles routing and state management using React Router and React Hooks.

Example of usage from the terminal:
npm start
Once the app is running, you can use it through the browser.
